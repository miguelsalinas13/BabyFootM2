# Visual finish texture sources

Photographic PBR maps from Poly Haven, CC0:

- Fine Grained Wood: https://polyhaven.com/a/fine_grained_wood
- Concrete Floor 02: https://polyhaven.com/a/concrete_floor_02
- License: https://polyhaven.com/license

Original downloaded maps and hashes are recorded in TEXTURE_SOURCES.json.
The Unity materials use the OpenGL normal maps and convert roughness to smoothness.
No reference photograph pixels are included in the project assets.
