# Editable Blender sources

These four source snapshots accompany the imported BabyFoot FBX assets in Assets.
They live outside Assets so Unity does not invoke Blender to import .blend files.
The unrelated Tennis Stadium source is intentionally not part of BabyFoot.

Save future source edits here, export FBX into the existing asset paths, and let
Unity preserve the existing .meta files. ASSET_NOTES.md files describe the original
model conventions and may contain historical pre-import validation notes.
SOURCE_INVENTORY.json records the initial copied snapshots; regenerate it after
intentional source changes if using it as a checksum inventory.

Blender sources are Git LFS files. No unsaved live Blender session is captured.
